# ProXPL Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.6.x   | :white_check_mark: |
| < 1.6   | :x:                |

## Reporting a Vulnerability

Please report vulnerabilities privately by emailing security@proxentix.com or using the GitHub Security Advisories feature.
Do NOT open a public issue for an unpatched security vulnerability.

## Expected Response Time
We will acknowledge receipt of your vulnerability report within 48 hours.

## Security Update Policy
Security updates will be released as patch versions (e.g., 1.6.4). We will provide an advisory outlining the vulnerability and the fix.
