# Installation

## Option 1: Pre-built Binaries (Recommended)

Download the latest release:
- **Windows**: [proxpl.exe](https://github.com/ProgrammerKR/ProXPL/releases/latest)
- **Linux**: [proxpl](https://github.com/ProgrammerKR/ProXPL/releases/latest)
- **macOS**: [proxpl-macos](https://github.com/ProgrammerKR/ProXPL/releases/latest)

Add to your `PATH` for global access.

## Option 2: Build from Source

See [Build Guide](BUILD_GUIDE.md) for detailed instructions.

## Option 3: CLI via Node.js

```bash
cd src/cli
npm install
npm link
```

Now use `prox` globally with enhanced features.
