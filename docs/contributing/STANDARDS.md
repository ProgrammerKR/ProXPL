# Coding Standards

ProXPL coding standards and style guidelines.

## C/C++ Code Style

- **Indentation**: 4 spaces
- **Braces**: K&R style
- **Naming**: `camelCase` for functions, `PascalCase` for types, `UPPER_CASE` for constants
- **Headers**: Include guards with `#ifndef`
- **Comments**: Descriptive for complex logic, avoid trivial comments

## Commit Messages

Follow [Conventional Commits](https://www.conventionalcommits.org/):
- `feat:` - New features
- `fix:` - Bug fixes
- `docs:` - Documentation changes
- `refactor:` - Code refactoring
- `test:` - Adding tests
- `chore:` - Maintenance tasks

## Pull Requests

1. Reference an issue if applicable
2. Include tests for new features
3. Update documentation if needed
4. Follow the pull request template
