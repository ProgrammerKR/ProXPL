# ProXPL v1.6.3: The "Wasm World" Release

**Target Release Date:** Q2 2027  
**Status:** Released  
**Codename:** Wasm World

---

## 🌟 Overview

ProXPL v1.6.3 ("Wasm World") introduces a production-grade **WebAssembly compilation target**, enabling ProXPL programs to run directly in browsers and edge runtimes. This release also brings **Closures v2** with compiler-level escape analysis and upvalue deduplication, **String Templates** with backtick interpolation, user-defined **Operator Overloading**, the **ProXPL Code Formatter** (`prox fmt`), and **Enhanced Compiler Diagnostics** with error codes and typo suggestions.

---

## ✨ New Features

### 1. WebAssembly (Wasm) Target
Compile ProXPL to valid WebAssembly for browser and edge deployment.

```bash
# Compile to Wasm
proxpl build --target wasm app.prox
# Output: app.wasm + app.js (glue code)

# Serve locally
prm serve --wasm
# Opens browser at localhost:3000
```

**Features:**
- Full core language execution in WebAssembly 1.0 format
- JavaScript ↔ ProXPL interoperability bridge
- `std.web.dom`: DOM element creation, queries, style, and attribute manipulation
- `std.web.event`: Event listener subscription and dispatch
- `std.web.http`: HTTP Fetch API integration
- `std.web.canvas`: 2D Canvas rendering operations
- WASI preview1 support for stdout/stderr streaming
- Explicit capability safety preventing unsupported native FFI/filesystem calls in browser environments

### 2. String Templates (Template Literals)
Embedded expression interpolation inside backtick-delimited strings.

```javascript
let name = "World";
let age = 25;

// Template literal syntax
let greeting = `Hello, ${name}! You are ${age} years old.`;

// Multi-line templates
let html = `
    <div class="card">
        <h1>${name}</h1>
    </div>
`;

// Escaped expressions
let escaped = `Literal \${expression}`;
```

---

### 3. Operator Overloading
Custom operator implementations for user-defined classes and types with inheritance support.

Supported operators: `+ - * / % @ == != < > <= >= [] []= () - !`

```javascript
class Vector2D {
    let x;
    let y;

    func init(x, y) {
        this.x = x;
        this.y = y;
    }

    operator +(other) {
        return new Vector2D(this.x + other.x, this.y + other.y);
    }

    operator [](index) {
        if (index == 0) return this.x;
        if (index == 1) return this.y;
        return null;
    }
}
```

### 4. Closures v2 & Escape Analysis
Compiler-level escape analysis distinguishing non-escaping closures from escaping closures:
- Non-escaping closures execute stack-locally with zero heap allocation overhead.
- Escaping closures are tracked on the GC heap with upvalue deduplication.
- Proper per-iteration bindings for captured loop variables.

---

### 5. ProXPL Formatter (`prox fmt`)
Official, deterministic, syntax-aware formatter.

```bash
# Format single file
prox fmt app.prox

# Format project
prox fmt .

# Check formatting without modifying
prox fmt --check .
```

Supports `.proxfmt.pxcf` configurations including indentation style, max line length, brace style, trailing commas, and import sorting.

---

### 6. Enhanced Compiler Diagnostics
Rust/Clang-grade diagnostic reporting with stable error codes, source code snippets, carets, and typo suggestions:

```
error[E0412]: Undefined variable 'naem'
  --> src/main.prox:15:12
   |
15 |     print(naem);
   |           ^^^^ not found in this scope
   |
   = help: Did you mean 'name'?
```

## 🔧 Breaking Changes

- Backtick (`` ` ``) is now reserved for String Template Literals.
- Keyword `operator` is now a reserved keyword.
