# Release Notes for ProXPL v1.3.6

## What's New

### 1. Security Fixes
- **Command Injection Fixed (`prm publish`)**: Resolved a high-severity OS command injection vulnerability in the package manager. The `prm publish` command previously used unvalidated input from the `project.pxcf` manifest inside a `system()` call. Input strings for `name`, `version`, and `entryPoint` are now strictly validated against shell metacharacters and quotes to prevent arbitrary code execution on the host machine.
- **Dependency Updates (`extension`)**: Resolved several high-severity security vulnerabilities reported by Dependabot in the VS Code Extension NPM dependencies:
  - Fixed `esbuild` development server arbitrary file read vulnerability (CVE/GHSA-g7r4-m6w7-qqqr) by forcing an update to `0.28.1`.
  - Fixed `brace-expansion` Denial of Service (DoS) vulnerabilities by overriding the transitive dependency version to the secure `2.0.1` patch release in NPM overrides.

### 2. Version Updates
- Updated all language package versions (`CLI`, `VS Code Extension`, `Language Server`, `Inno Setup`, and `CMake`) to `1.3.6`.
