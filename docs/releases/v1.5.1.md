# ProXPL v1.5.1: Benchmark Suite Expansion

**Release Date:** July 31, 2026

## 🚀 Overview

Version 1.5.1 brings comprehensive updates to our performance benchmarking suite, ensuring that ProXPL is accurately tested against a wider range of competitive languages and frameworks.

### ✨ What's New

1. **Expanded Reference Benchmarks**:
   - We have fully populated the `benchmarks/reference` directory with missing implementations for C++, Java, and Go.
   - You can now properly compare ProXPL's execution times in `array_ops`, `collatz`, `dict_access`, `matrix_mul`, `nbody`, and `primes` against high-performance compiled languages directly in CI.

2. **New Merge Sort Benchmark**:
   - We've added a robust `merge_sort` macrobenchmark across all supported languages (ProXPL, Python, JavaScript, C++, Java, Go) to evaluate deep recursion, list operations, and allocation pressure.

3. **CI/CD Readiness**:
   - The benchmarking scripts are now fully prepared to run on GitHub Actions using the `ubuntu-latest` environment. The `run_benchmarks.py` script dynamically binds to GCC, OpenJDK, and Go toolchains provided by the CI.

### 🐛 Bug Fixes
- Fixed the benchmarking suite reporting `N/A` for C++, Java, and Go by implementing the missing algorithmic equivalents.
- Updated `compile_tests.bat` wrapper to properly forward test execution to CMake and CTest.

### 📝 Documentation
- Global version bump across the codebase, `SPEC.md`, and build definitions to reflect the `1.5.1` stable patch.
