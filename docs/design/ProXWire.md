# ProXWire: Distributed Runtime

Experimental distributed runtime and messaging system for ProXPL.

## Overview

ProXWire provides node-to-node communication and distributed computation primitives.

## Status

**Status**: Experimental - Concept and design documented, implementation in early stages.

## Features (Planned)

- Node discovery and registration
- Message passing between distributed nodes
- Distributed data types (`distributed`, `node`)
- Actor-model primitives

## Current State

Keywords (`node`, `distributed`) are reserved in the lexer but the runtime execution loop does not yet support message passing or actor semantics.
